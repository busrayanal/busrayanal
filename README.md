# Hi, I'm Büşra 👋

I'm a Computer Engineering student at **Erzincan Binali Yıldırım University** who loves building software across different fields. On the defense side, I work on algorithms, simulation and software integration for **Fighting UAV**, **Swarm UAV** and **air defense** projects, and I'm proud to be a **TEKNOFEST 2026 finalist**. On the creative side, I enjoy making **games**, **web apps** and **3D designs**.

## 🚀 Teams & Competitions

- 🏆 **İstikbal Swarm Team** · *Software Team Member*: Finalist in the TEKNOFEST 2026 Swarm UAV Competition. I contribute to the algorithms, testing and simulation of multi-UAV systems.
- 🎯 **Praxis Team** · *Software Team Lead*: Leading image processing, target tracking and embedded software integration for an air defense turret.
- ✈️ **İstikbal Team** · *Software Team Member*: Developed a YOLO and Kalman filter based visual lock-on and autonomous target tracking algorithm for a fighting UAV.
- 🌱 **GDG on Campus EBYÜ** · *Board Member*: Managing visual content and design for the club's events and social media.

## 🎨 Beyond Competitions

- 🎮 **Game development:** From desktop games in C# to browser games in JavaScript, like the [mini game platform](https://github.com/busrayanal/GDG-Mini-Game-Stand) I built for our GDG stand ([play it here](https://busrayanal.github.io/GDG-Mini-Game-Stand/)) and a [minefield game](https://github.com/busrayanal/Minefield-Game) in WinForms. I also experiment with Unity.
- 🌐 **Web development:** Building interactive, offline-friendly web apps with plain HTML, CSS and JavaScript.
- 🧊 **3D design:** Designing models in Fusion 360, including scripting designs with Python.
- 🖌️ **Visual design:** Creating posters, social media content and materials for club events.
